# Team Quiz — Project Guidelines

A single-screen **team quiz game** with a Jeopardy-style board. Teams take turns
picking a category and a point value, answer against a timer, and the next team
can steal a missed question for half the points. All questions are generated by
an AI agent in the chosen language when the game starts.

This document is the source of truth for what we're building.

---

## 1. Format

- **Play style:** one shared screen (laptop / TV / projector). No player phones,
  no accounts, no online play.
- **Teams:** 2–5, named in setup.
- **Board:** 3–15 categories. Every category holds three questions worth
  **2**, **4** and **6** points (2 = easiest, 6 = hardest).
- **Board interaction:** the board shows category tiles. Clicking a category
  opens its remaining point values; picking one starts the question. Played
  values disappear from that category; an emptied category is closed out.
- **Turns:** rotating. The active team picks any remaining category + value.
- **Steal:** if the active team misses, **only the next team in order** may
  steal. A correct steal scores **half** the value (1 / 2 / 3 points).
- **After a steal:** the team that stole picks the next question. (A successful
  steal seizes the turn.)
- **Game end:** set in setup — either the board is emptied, or first team to
  reach a target score.

## 2. Setup screen

| Setting | Values |
|---|---|
| Language | English · Spanish · Lithuanian |
| Teams | 2–5, with names |
| Categories | 3–15 — pick from a preset catalogue, type custom ones, or randomize |
| Time per question | 60 / 120 / 180 seconds |
| Difficulty | Casual · Balanced · Hard (shifts how hard each point tier is) |
| Speed bonus | On / Off (default On) |
| Game end | Board emptied · First to N points |

## 3. Question types

| Value | Type | How the team answers |
|---|---|---|
| **2 pts** | Multiple choice, 4 options | Click an option |
| **4 pts** | Open text | Type the answer |
| **6 pts** | Open text | Type the answer |

## 4. Grading

- **Multiple choice** is graded exactly.
- **Open text is graded by the AI**, which already holds the correct answer and
  its accepted variants. It must accept an answer with **minor spelling or
  typing mistakes** — a misspelled right answer is a right answer.
- **Manual override:** the reveal screen always shows **Accept** and **Reject**
  buttons so the host can overrule the AI in one click.

## 5. Scoring

- Correct on your own turn: **2 / 4 / 6** points.
- Correct on a steal: **1 / 2 / 3** points.
- Wrong answer: **0**. No penalty, no negative scores.
- No answer before the timer ends: **0**.
- **Speed bonus (optional, default on):** **+1** point when answered within the
  first 15 seconds. Steals do **not** earn the speed bonus.
- **Ties are allowed** — tied teams share the win. No tie-breaker round.

## 6. Question generation

Questions are generated by an AI agent, **all at once when the game starts**,
not mid-game. A short loading screen with a progress bar covers this; from then
on the game runs with zero waiting.

- **Volume:** 3 categories = 9 questions, 15 categories = 45 questions.
- **Per question the generator receives:** language, category, point value
  (shaped by the difficulty setting), and the required format (4-option multiple
  choice at 2 points, open text at 4 and 6).
- **Verification pass:** every generated set is checked by a second call that
  confirms the stated answer is correct, that a multiple-choice question has
  exactly one correct option, that nothing is ambiguous, and that it is in the
  right language. Corrections are applied; anything unfixable is regenerated
  once, then dropped.
- **No duplicates** within a game.
- **Structured output:** questions come back in a fixed schema — prompt,
  options (MC only), correct answer, accepted alternate answers.
- **Model:** Claude `claude-opus-5` via the Anthropic API.
- **Failure path:** if a question can't be generated or verified after retries,
  that cell is dropped from the board rather than blocking the game.

## 7. Persistence

Game state auto-saves to browser storage, so an accidental refresh doesn't
destroy a game in progress. No accounts, no server-side history.

## 8. Tech direction

- **Frontend:** React + TypeScript, single page, driven from one keyboard.
- **Hosting:** Vercel.
- **Question service:** a Vercel serverless function that holds the Anthropic
  API key and returns validated question JSON. The key never reaches the
  browser.
- **State:** in-memory game state mirrored into browser storage.
- **i18n:** UI strings in per-language files; question content is generated in
  the selected language.

## 9. Build sequence

1. **Setup screen + board** — configure a game, render category tiles and the
   point values behind them, turn rotation, scoreboard.
2. **Question flow** — timer, answering (MC and open text), reveal, steal,
   scoring, manual accept/reject.
3. **AI generation** — the generate-and-verify service, all three languages,
   loading screen.
4. **Polish** — end-of-game screen, sounds, animations.
