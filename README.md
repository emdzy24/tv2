# Team Quiz

A single-screen party quiz for teams. Pick a category, pick a point value,
beat the clock — and if you miss, the next team steals it for half.

- **Teams:** 2–5, one shared screen
- **Board:** 3–15 categories × 2/4/6-point questions
- **Questions:** generated by AI at game start, in English, Spanish or Lithuanian
- **Answering:** multiple choice at 2 points, typed answers at 4 and 6
- **Grading:** AI marks typed answers and forgives typos; the host can override
